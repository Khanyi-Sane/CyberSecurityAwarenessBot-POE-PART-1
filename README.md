## Project Description

The Cybersecurity Awareness Chatbot is a C# console application designed to help users learn basic cybersecurity practices. The chatbot provides information and guidance about password safety, phishing, and safe browsing. It also uses a personalised greeting, voice greeting, ASCII art, input validation, and coloured console text to make the application more interactive and user-friendly.

## Features

* Voice greeting using `greeting.wav`
* ASCII art displayed when the application starts
* Personalised greeting using the user's name
* Password safety responses
* Phishing awareness responses
* Safe browsing responses
* Input validation for blank or unsupported input
* Coloured console interface
* Keyword-based responses to user questions

## How to Run

1. Clone or download the repository from GitHub.
2. Open the project/solution in Visual Studio.
3. Ensure that `greeting.wav` is located in the correct project folder.
4. Build the project to check that there are no errors.
5. Run the application by pressing **Ctrl + F5**.
6. Follow the instructions displayed in the console.

## Requirements

* Windows operating system
* Visual Studio
* The correct .NET SDK/framework version required by the project
* Windows audio support for the voice greeting
* `greeting.wav` audio file
